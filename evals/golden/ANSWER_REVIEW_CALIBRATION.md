# 答案复核口径

适用于当前 32 题 `golden_dataset.json`（28 可答 + 4 拒答）。复核只判断实际交付正文和实际交付引用，不使用参考答案、检索结果、引用卡片或未交付草稿替正文补内容。

## 逐事实状态

| 状态 | 判据 | 必要事实 Recall |
|---|---|---:|
| `covered` | 完整表达必要命题，允许同义改写、合并叙述和上下文明示的指代 | 1 |
| `partial` | 已表达一部分，但缺必要语义、关系或限定 | 0 |
| `missing` | 已读完整正文，没有表达该必要命题 | 0 |
| `contradicted` | 明确断言与命题冲突，含未消解的正反并存 | 0 |
| `unknown` | 尚未复核，或现有材料不足以可靠判断 | N/A |

`partial` 不折算成部分分。复合事实里的检查点只帮助说明判定，仍只占一个单位。

## 逐引用状态

| 状态 | 判据 |
|---|---|
| `supported` | 实际交付引用可核验，并支持本条已经表达的主张 |
| `partial` | 支持已表达主张的一部分，仍缺跨页或关系等必要证据 |
| `unsupported` | 已核验却无引用、无关、绑定错误或截断，不能支持主张 |
| `unknown` | 未核验，或现有材料不能可靠辨认 |
| `not_applicable` | 正文没有表达该主张，并给出适用性理由 |

正文缺失的事实不能同时标为已经受到引用支持。引用卡片比正文更完整，不能补正文覆盖。

## 答案维度

每个适用题必须明确判断或写 N/A 理由：

```text
citation_support
source_constraint
time_constraint
routing
safe_refusal
scope_explanation
```

- 有硬来源约束的题不能跳过来源维。
- 有明确时间条件的题不能跳过时间维。
- 拒答题重点看是否拒答、是否编造正向事实、是否说明范围/材料边界。
- 没有可观察轨迹时，路由维保持 unknown，不判 N/A。
- 引用支持要检查所有事实断言，包括最低事实之外的扩展；扩展正确且有据可接受，扩展错误或无据应判失败。

## 当前 32 题的最低覆盖

- 精确事实题：日期、机构、职务必须逐项对应，不能把相近日期或相近机构当同义。
- 语义/观点题：允许同义改写和有据扩展，但必须表达冻结的最低事实。
- 多证据/跨期题：按证据组 AND/OR 核对；跨年题按年份或阶段组织，不能只答端点。
- 交集题：只接受原文直接支持的共同动作；人名共现、同页出现、单方活动不算。
- 约束题：来源、月份、地点同时核对；同月异地不能替代。
- 拒答题：拒答不等于历史否定；资料不足、来源范围不足和项目范围越界要区分。

## 禁止

- 不能只检查引用编号存在就判引用通过。
- 不能把“引用里有正确事实”当成“正文已覆盖”。
- 不能因为答案风格、篇幅或未要求的扩展扣分。
- 不能把未复核项按 0 分处理。
- 不能把 Agent 预标注或 LLM judge 当作人工批准。
