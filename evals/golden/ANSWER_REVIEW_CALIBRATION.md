# 开放题答案复核口径

本文件及 `answer-calibration-v1` 是依据冻结开发集、协议和旧 13 题观察整理的复核辅助说明。判例是 Agent 建议，待人工核验；不是新增历史标签或已获人工同意的校准共识。它不修改 Agent、冻结标注、既有判断或历史得分。已有人工作出的新“三人团”旬别裁定继续适用，且只适用于该争议。

20 个独立题保持 85 项必要事实。淮海题的两臂分别复核，控制臂的 10 项事实不并入主报告分母。三个拒答题没有正向事实分母。正式 Golden 成绩仍需整题人工批准及本次答案的人工复核；使用工作台、填写姓名或选择 `human_review` 都不会批准题目定义。

## 先看正文，再看引用

逐事实判断的是实际交付正文。参考答案、金标原页、检索结果、引用卡片和未交付的草稿都不能替正文补出缺失内容。随后独立核对实际交付引用是否支持正文表达的主张：正确的正文可能引用无据；正文只回答一半，也可能这一半都有可靠支持。

| 状态 | 统一判据 | 必要事实 Recall |
| --- | --- | --- |
| `covered` | 完整表达必要命题，允许同义改写、合并叙述及上下文明示的指代 | 计 1 |
| `partial` | 已表达一部分，但缺必要语义、关系或限定 | 不计完整覆盖 |
| `missing` | 已读完整正文，没有表达该必要命题 | 不计完整覆盖 |
| `contradicted` | 明确断言与命题冲突，含未消解的正反并存 | 不计完整覆盖 |
| `unknown` | 尚未复核，或现有材料不足以可靠判断 | 完整 Recall 为 N/A |

保留 `partial` 的含义，避免把“有用但不完整”描述为“一无是处”。当前指标仍是二值完整覆盖率，不给部分分，不因引入工作台而降低通过阈值。一个复合事实里的检查点帮助说明判定，仍只占原来一个单位。

正文已经明确绑定主体、时间或机构时，不要求每句话重复。反面提醒不是必须照抄的句式，例如正确说明 1954 年书记处书记任职，无须额外逐字写“中央副主席是 1956 年”；但若把后者前移到 1954 年，必须指出冲突。不能把关键语义缺失与措辞差异混为一谈。

| 引用支持状态 | 统一判据 |
| --- | --- |
| `supported` | 实际交付引用可核验，并支持本条已经表达的主张 |
| `partial` | 支持已表达主张的一部分，仍缺跨页或关系等必要证据 |
| `unsupported` | 已核验却无引用、无关、绑定错误或截断，不能支持主张 |
| `unknown` | 未核验或现有材料不能可靠辨认，不等于已证实无据 |
| `not_applicable` | 正文没有表达本条主张，并给出适用性理由 |

新口径下 `covered`、`partial`、`contradicted` 须带正文逐字摘录，允许空白差异；支持为 `supported` 或 `partial` 须选择真实交付的证据 ID。正文缺失的事实不能同时标为已经受到引用支持。合理拒答不需要虚构正向历史引用；如果已交付出版说明等元证据，则仍要核对它是否支持范围说明，不能将元证据计成正向事实。

全回答的 `citation_support` 需检查所有事实断言，包括最低清单以外的扩展。扩展内容正确且有据可接受，不扩大本版事实分母；扩展包含错误或无依据断言应判失败，尚未核查应保持未知，不能只检查必要事实就判通过。

## 开放题的最低覆盖

`facts` 是本版可复核的最低要求，`reference_answer` 不是唯一标准答案。不因标题、措辞、顺序、篇幅或未要求的扩展扣分，也不能借“开放题”忽略已经冻结的必要内容。

| 题目 | 本版边界 |
| --- | --- |
| 农业生产形式 | 实效、群众意愿、形式多样三项分别核对；只有猫的比喻不能代替三项关系 |
| 遵义及会后军事领导 | 区分会议、2 月 5 日、3 月三阶段；新三人团只要求 3 月、毛周王、周恩来团长及职责，中旬/下旬不硬评分 |
| 周恩来 1954 年主要职务 | 保持六项最低事实；年初政务院至 9 月国务院、政协副主席至 12 月主席的转换不能省略，其他有据职务可补充 |
| 周恩来 1954—1956 年经历 | 六类代表活动加跨年综合；有列表但无工作重点变化仍缺综合，归纳不应声称各年只有这些工作 |
| 调查研究观点 | 四项最低观点；允许改写与有据扩展，反本本主义不能被改成反理论学习 |
| 《矛盾论》主要矛盾 | 区分主要矛盾与矛盾的主要方面；保留具体条件/阶段变化导致主次转换关系，只列对立双方或说“有主要矛盾”不足 |
| 两次会议比较 | 两会议分别覆盖核心问题、进程与影响；允许其他有据角度，原文评价应有出处，先后关系不能自动变因果 |
| 淮海战役 | 两臂都核对同十项最低事实；答案相似或都正确不能代替四项过程隔离检查，旧轮林彪与旧年份不能污染当前问题 |
| 湖南逐年活动 | 固定六年，事实数为 2、2、2、1、5、2；1925 年五项不能抵消漏掉 1924/1926，湖南外活动不计湖南事件，1927 年不能前移 |
| 毛周 1949 年交集 | 五个代表性共同动作，不是全年全集；两人同页出现、单方活动或泛泛同时任职不能当同一动作 |

三项拒答边界应区分：2024 年超出项目研究范围；爱因斯坦 1925 年是本地证据不能支持题设，允许询问党派；指定 1904—1974 年谱不能支持 1975 全年活动，即使书中提及次年计划。后二者不是项目时间越界。资料不足都不等于历史事件不存在。

来源标注的 `annotation_sources_not_exclusive` 表示金标取材范围，不是额外硬过滤；`hard_user_constraint` 才要求遵守题干限定来源。时间、地点、共同动作及出处限定应按题干与协议核对，不把书名年代或页眉当事件日期，也不把收电人地点当发电地点。

## 判例的使用方式

以下均是合成的评分示例，不是本轮答案标签。工作台会在适用题目旁显示同类提示；复核者仍须阅读当前答案与实际引用。

- “应尊重农民意愿，采用他们愿意采取的生产形式”可完整覆盖群众意愿命题；“群众要求有道理，应研究”仅部分覆盖选择原则。
- 正文只说恢复组织生活和副总理职务，缺“由国务院分配适当工作”，即使引用完整也仍为 `partial`；引用支持已表达部分可以同时为 `supported`。
- 重要政策列席政治局的内容只存在引用卡片，完整正文没写，事实为 `missing`，不能补成 `covered`。
- 1952 年任命写成“国务院副总理”与“政务院”冲突，不能当作同义改写。
- 新三人团用月份完整表达成员、团长和职责，可为 `covered`，不因未写旬别扣分。
- 材料损坏使复核者读不到完整答案可以暂记 `unknown`；已经完整读到并确认只是少写了一部分，应记 `partial`。

旧 13 题观察提示的主要分歧点正是复合事实、正文与引用分离、年份/职务转换和综合关系。此处引用这些问题类别以校准后续复核，不复制旧判断到新答案，也不批量提高旧分数。

## 可追溯与比较

评测工具生成 `calibration.json`，记录版本、完整数据集哈希、协议哈希、逐题定义哈希、每条原命题及证据组、JSON 路径和专项边界。内部 `calibration_sha256` 对该字段之外的包内容取规范化哈希；答案复核和导入包绑定的是完整校准包的 `fingerprint(packet)`，两者范围不同。

逐题额外解释只对本次已检查的冻结定义生效；若同题 ID 的定义改变，不自动沿用原解释。通用正文/引用规则仍可生成，需重新检查新版本的逐题判据。校准包自身被改动后不能仅更新哈希蒙混导入，导入时按版本和绑定输入重建校验。包的变化要求同口径重审比较双方，不得把旧无版本答案与新口径分数当作直接进步证据。

工作台帮助整理判断，不自动判断语义。明确结果需要实质理由、复核身份和带时区时间。`routing` 缺轨迹应保持未知而非不适用；已知存在事实或交付引用的引用维、拒答的安全/范围维、明确硬来源和时间限定不得以 N/A 跳过。没有这些确证适用条件的维度仍可给出具体理由判为不适用。

本口径不补齐新增题目的候选相关性标注，不把缺标签候选当不相关，也不把答案的便利复核替代召回、排序、上下文和过程评测。
