# 题目定义复核表（15 道待批准题）

本表只用于批准**题目定义**：问题、必要事实、证据组与锚点、回答边界、拒绝依据。批准不等于批准候选标签、排序池或历史答案，后两者仍需单独处理。

## 怎么回复

逐题给一个结论，修改项写清楚改哪一条即可，例如：

```text
dev_multi_mao_hunan 批准
dev_multi_meetings 改事实：fact X 应改为……；其余批准
holdout_semantic_observation 改锚点：组 Y 的页码应为 PDF 123，引文改为“………”
holdout_intersection_negative 删题，原因：……
```

判定标准：

1. 问题是否精确对应必要事实，不多不少；
2. 每条必要事实是否至少有一组可验证锚点（同一锚点可服务多组，但组间不能互相替代）；
3. 锚点引文是否能在标注页原文中找到，且语义确实支持该事实；
4. `forbidden_claims` 是否覆盖该题常见的错误说法；
5. 拒答题的拒绝依据是否成立，且没有把“当前语料没有”说成“历史上不存在”。
