## 已定位问题与下一步

1. **先修执行计划的约束保留。** 1973题原始Planner响应正确返回1973年、3月条件和5条查询；实际执行计划却变为1904—1974、查询列表为空，最终还引用了下卷以外的材料。这是模型规划之后的约束污染，应以该题及来源/月份相邻案例验证。
2. **再修上下文和引用片段的完整性。** 一大中央机构片段被截断；周恩来1954的职务引句受损；遵义答复把猴场会议规定挂到遵义。先区分完整句保留、同页不同事件归属和摘要传递，再做单变量实验，不先盲目增大Top-K。
3. **补足事实覆盖与回退质量。** 1973及周恩来跨年题的摘录回退没有完成原问题要求；农业、职务年内变化等题有明确必要事实遗漏。结合严格事实Recall和成本评价修复收益。
4. **继续评测基础设施工作。** 扩充前10/20位真实候选的人工可复核分级，接通新7题协议与多轮两臂，再跑固定版本20题开发集；10道保留题继续隔离。摘要映射和结构化检索轨迹仍是过程可评性的缺口。

本轮只观察和评审，未修复Agent问答行为，因此不新增“已修复”badCase记录。
